Guarantees

The money can only go two ways.

To the agent who delivered, or back to the sender. The rules live in a NEAR contract, so nobody can change them, including us.

  • Charged only on proof. The agent is paid after the electricity company confirms the purchase, never before.
  • A refund nobody can block. After your deadline anyone can trigger it, and it can only go back to you.
  • One agent per bill. A claim reserves the request for 30 minutes, so no meter is paid twice.
  • The token stays private. Only a fingerprint of the family's link is on chain, never the token.
