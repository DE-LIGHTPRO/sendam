Guarantees

The money can only go two ways.

To the agent who delivered, or back to the sender. The rules live in a NEAR contract, so nobody can change them, including us.

  • Charged only on proof. The agent is paid after the electricity company confirms the purchase, never before.
  • A refund nobody can block. After your deadline anyone can trigger it, and it can only go back to you.
  • One agent per bill. A claim reserves the request for 30 minutes, so no meter is paid twice.
  • The token stays private. Only a fingerprint of the family's link is on chain, never the token.

Questions

The things people ask first.

Who holds my money while I wait?

A contract on NEAR, not Sendam and not the agent. It can only release the USDC to the agent whose payment was confirmed, or return it to you.

What if no agent pays the bill?

You choose a deadline when you send (24 hours by default). You can cancel any time before an agent takes it, and after the deadline anyone can trigger the refund, which can only go back to your wallet.

Does my family need a wallet or an app?

No. They open the link you send, watch the payment arrive, and read the token off the screen. The link is private: only a fingerprint of it is stored on chain.

What does it cost?

You set the exchange rate and a tip for the agent, and see the total in USDC before you lock anything. Sendam adds no fee in this prototype.

How do I know the agent really paid?

The agent is not paid on their word. A verifier checks the purchase with the bill provider, matching the meter and the amount, before it tells the contract to release the money.

Is this real money?

Not yet. This prototype runs on NEAR testnet with test USDC, and the bill provider runs in a sandbox or simulated mode. The README lists exactly what is real and what comes next.
